# Changelog

## v0.2.0

- Replaced the 2× restoration approach with an original minimalist semantic icon system.
- Added 53 original atlas cells and mapped 247 marker IDs to 50 gameplay categories.
- Preserved faction identity and anomaly type through restrained category-specific colors.
- Reduced transition and low-priority marker sizes to prevent global-map clutter.
- Disabled zoom-driven marker growth and reduced transition markers to 5×5.
- Resized nested objective borders together with their primary icons.
- Replaced the cyan-heavy palette with ivory, amber, rust, sage and steel roles.
- Preserved directional headings, objective blink timing, map levels and marker bindings.
- Added a ready-to-install MO2 archive to tagged GitHub releases.

## v0.1.0

- Added a local builder for five conservative 2× HD marker atlases.
- Added 94 layer-specific DXML rules that preserve original marker geometry, colors, borders, factions, animations, and configured display sizes.
- Removed the earlier generic 20-glyph implementation because it collapsed distinct marker layers and states.
- Added inventory, atlas-bound, build-plan, DDS, hash, and output-layout validation.
- Added a one-command PowerShell build path for MO2 users.
